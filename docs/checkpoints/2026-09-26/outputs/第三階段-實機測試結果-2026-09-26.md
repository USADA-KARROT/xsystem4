## 量測與限制

| 項目 | optimized | ASan |
|---|---:|---:|
| 完整 PERF 報告窗 | 6 | 6 |
| 已報告 present 加權頻率 | 532.824／秒 | 367.689／秒 |
| 已報告最長 present 間隔 | 82.017 ms | 1296.697 ms |
| 最長 swap 耗時 | 11.922 ms | 8.543 ms |
| 程序峰值 RSS | 625.141 MiB | 1058.766 MiB |
| 字串重複釋放警告行數 | 10627 | 4650 |
| allocator free-list 異常行數 | 1 | 1 |
| 停止原因 | error_log | error_log |

present 次數可能包含相同畫面，vsync=0；這些高數字不能稱為可玩 FPS，也不能代表劇情正常。ASan 有額外檢查成本，不與 optimized 直接比較速度。已報告的 ASan 長間隔約 1.3 秒，顯示本次確有明顯停頓。

PERF 在完成 present 後才 flush，未涵蓋不足五秒的尾窗或最後一幀後沒有完成下一幀的停頓。因此 optimized 的 82 ms 不能排除結束前更長的卡住。RSS 是整個程序的峰值，非 live AIN heap，不能單次判定洩漏。

兩輪 child exit_code 都是 0，但 runner 已明確記錄 error_log，**不能判定為通過**。已修正測試工具這個回報缺口：日後 error_log 即使 child exit0，runner 仍回傳失敗狀態。這是測試工具修正，不是引擎修復；沒有為此重跑相同 GUI 失敗流程。
