# 獨立審查摘要

2026-10-18。兩個獨立的唯讀審查：一個看根因與修法，一個看畫面與探針。完整報告留在私人工作區。兩邊都沒有 High。

## 根因與修法

審查者自己用反組譯重讀了 `0x540050` → `0x55e400`、`0x56d620`、`0x53d660`、`0x539c80`、`0x579160`、`0x53aa80` → `0x53b270` → `0x53b180`、`0x534f00`，確認：

- 原版逐號釋放、子元件改掛到樹頂的根。
- 移植版用子元件自己的控制器找根，因為子樹的控制器跟著父元件走，所以和原版等價。

根因的每一段都對得上實機紀錄：

- 第一場結束時，技能面板的樹在行動面板的釋放裡被拆掉。
- 第二場載入時，有五則「已註冊、跳過」的警告。
- 腳本拿到的是第一場留下的選擇器。

另一條佐證：物件池清層時沿父元件鏈找圖層。修改前被連帶釋放的元件對不上圖層，會留下空殼；修改後能被正確移除，回到原版的設計。

Medium 是回歸範圍：存檔、庫房、系統選單、回顧這幾條路線沒有跑。提交後已經補跑，見研究文件的路線表。
