### 判讀前要先知道的兩件事

1. **Wine 的字型不是原版字型。** 這個 Wine prefix 用 SimSun 偽裝成 MS Gothic（見 `~/Claude/CLAUDE.md` 方案 1），所以 Wine 截圖裡的明體字是環境造成的。實機截圖是黑體，和 xsystem4 的 VL Gothic 同一類。字形與字距因此以實機截圖為準。
2. **原版截圖的對白都是「已讀」色。** EX 的 `Ｅ＿已讀信息色` 是 (255,203,57)。Wine run3 與實機截圖的字都是這個金色，而 xsystem4 每次都是新存檔。詳見 D12。

## 建議修正順序

1. **據點 UI 元件缺失（D1、D4、D5，連帶 D2）**：先查 SceneAzito 的底列、Day／金錢、貼紙 parts 為什麼沒有建立或沒有繪製。「下一步」不能按就無法推進遊戲，教學覆蓋層很可能也卡在同一處。
2. **`PartsEngine.SetButtonEnable`（D3）**：原因明確、範圍小。實作停用狀態（灰階加上不可點擊）。
3. **訊息視窗系統 UI（D8、D9、D10）**：KeyWait（NEXT）的 CG 與動畫、AUTO／LOG 鈕、左下兩鈕的位置。三者都屬於同一個訊息視窗的 UI 群組，建議一起查。
4. **逐字顯示與訊息速度（D11）**：依 `GetMessageSpeedRate` 逐字淡入，並讓 `IsFixed`／`Fix` 回報真實狀態。這會影響點擊補完文字與推進的行為，要搭配現有的 WaitForClick 回歸測試。
5. **據點轉場與背景效果（D7、D6、D13）**：「據點環節」橫幅與等待點擊、背景模糊與色調、黑幕中的異常條帶。
6. **已讀文字色（D12）**：需要已讀紀錄與存讀檔持久化（目前的已知卡點）。完成後用有已讀紀錄的存檔重比。
7. **字距與行距微調（D14）**：和 text-metrics 的工作一起做，以實機截圖為基準（不要以 Wine 為準）。
8. **字型（D15）**：不需要處理。Wine 的明體是環境造成的。

## 配對方法與可信度

- **xsystem4 取樣**：每次自動點擊（1.2 秒）前 120 ms 存一張 framebuffer，檔名帶 SDL ticks 與當時最後執行的 MSG 編號 m。連續相同 m 視為同一頁。
- **相似度**（`tools/match.py`）：
  - **文字遮罩**：灰階 7×7 top-hat 與（膨脹後的）black-hat 取最小值，門檻 40，也就是「亮筆畫且緊貼暗描邊」。這對金／白字色與明體／黑體都不敏感。
  - **T（文字）**：採非對稱包含度，0.7×（原版筆畫被 xsystem4 解釋的比例）＋0.3×（反向）。原版常截在逐字顯示途中，所以以原版為分母。
  - **G**：全畫面 64×36 彩色縮圖 NCC。
  - **N**：名牌區 NCC。
  - **合成分數**：S = 0.6T + 0.25G + 0.15N。
- **對齊**：用單調動態規劃。相鄰兩張原版落在同一頁扣 0.03，跳過 k 頁扣 0.05k，分數低於 0.35 視為「無對應」。
- **結果**：
  - s001–s050 的 49 張對白截圖都配對成功，涵蓋 xsystem4 全部 48 頁。第 62／63 句在 xsystem4 是一頁中途停頓，對應原版 s033／s034；s024、s025 是同一頁的「未完／已完」。
  - s011、s051、s052 是轉場（低可信度，只拿來看轉場）。
  - s053–s130 共 78 張在 xsystem4 沒有對應畫面（教學覆蓋層）。
- **可信度**：
  - 文字分數 T：最低 0.87，中位數 0.96。全畫面分數 G 最低 0.978。
  - 與「其他頁最佳 T」的差距 margin：最小 +0.012（s018，單行短句），平均 +0.096；只有 s018、s024、s042 低於 0.03。
  - 不加順序約束的 T 最大值和動態規劃的選擇 49/49 相同。
  - **重現性**：vc1、vc3、vc4 三輪獨立執行，130 張原版截圖對到的頁與狀態 130/130 相同。
- **人工抽查**：`sbs/text/pairs_text_001-050` 的 49 組配對已逐張目視確認，台詞一致。實機截圖 C_game_002–026 也用同一套方法配對（`data/hw-vs-vc1/`），用來量字距與字型。

## 限制與未驗證事項

- 原版只有「按 Return 前」的單張截圖，所以轉場、動畫只能比對到被截到的那一刻。D13 沒有原版連續影格可以對照。
- xsystem4 停在據點之後，原版 s054–s130 的教學內容無從比對，只能確認「缺少」。
- D6、D7、D9、D10、D13 的原因沒有追到程式碼。D12 是否只是測試條件差異，要等已讀紀錄與存讀檔持久化完成後才能驗證。
- 字距數據（D14）的實機截圖經過 1891→1280 縮放，誤差約 ±1 px（整行）。行寬差 3～5% 遠大於這個誤差。
