# 捲軸的把手（設定畫面的橫桿、回顧）

2026-10-18。程式 `76fceaa`，基準 `f720846`，libsys4 固定 `247f544`。提交前、後的預設與 GBK 各 104 個模式 PASS。

## 症狀

設定畫面的橫桿看不到把手，例如信息速度、自動模式速度、跳過模式速度、聲音頁的音量；回顧的豎桿也一樣。數值、捲動訊息與「初始化」本來就有作用（10/11 那一組做的），只是什麼都沒有畫，按、拖也不動。使用者 10/18 試玩時指出。

## 原版依據

只做靜態分析，讀多娜多娜這一支執行檔。

| 項目 | 位址 | 內容 |
|---|---|---|
| CG 名稱 | `0x542a00`、`0x542b40`、`0x5748a0` | 把手是 bar 的 CG（或覆蓋名），加上普通、滑過、按住三個狀態；軌道是背景的 CG |
| 把手長 | `0x573e30` → `0x4e0870` | 把手 CG 沿軸的尺寸 |
| 把手位置 | `0x573bf0` | 軌道起點加 `trunc(((長 − 前 − 次) − 把手長) × 比率)`；原點座標模式以捲軸的尺寸移動 |
| 按下 | `0x572c30`、`0x572d90` | 按在軌道上時，先把把手中心移到游標 |
| 按住 | `0x572e00` | 比率 = 按下時的比率 + 游標位移 ÷ 可移動距離。按鍵事件送給按下時的元素，所以游標離開捲軸也照樣跟 |
| 放開 | `0x572f50` | 解除鎖定 |
| 更新順序 | `0x53c5b0` | 先跑輸入、再跑元件更新，所以拖曳造成的捲動訊息（21）在同一次更新送出 |

## 做法

- 捲軸元件自己畫軌道與把手兩張貼圖，和元件同一個座標系、倍率、alpha 與色。
- 輸入把捲軸當成一個目標，再判斷游標下是把手還是軌道，處理按下、按住、放開；滑過時把手換成滑過的狀態，按住時換成按住的狀態。
- `PE_Update` 改成先輸入、後捲軸更新，順序和原版相同。
- 只讀 GBK 拼法的 pactex 鍵。v14 之前的遊戲、沒有這些鍵的 pactex 都不畫、不動。

## 驗證

- **探針 `scrollbar-knob`**：11 案，說明見 [harness](../../harness/README.md)。期望值由探針裡另寫的算式算出。修改前 K1–K8 失敗，K9–K11 是守衛、修改前就該通過，見 [before.tsv](before.tsv)。另外做了 15 個故意改壞的突變，都有案例抓到。
- **兩組 verify**：提交前、後的預設與 GBK 各 104 模式 PASS，見 [verify.tsv](verify.tsv)。
- **和原版並排**（原版是 Wine 上的截圖，畫面只留在私人工作區）：
  - 設定第 1 頁三條、第 3 頁兩條、回顧的豎桿：把手的位置與大小都和原版一樣，用兩種量法量過。
  - 第 4 頁：把手的大小一樣，但位置不同，因為**值**不同，算式本身沒錯（見下面的限制）。
- **點軌道**（實機）：
  - 點第 1 頁的軌道，把手跳到算出的位置；按「初始化」回到預設。
  - 回顧點軌道，文字跟著捲動。
  - 按住的那一格拍到按住的狀態。
- **例行路線**：
  - normal150、haruuri、fightr、config、backlog 都跑完：時限結束、exit 0、錯誤 0。對白和前一組（APEG）或之前的紀錄逐字相同：88／629／681／88／88 句。
  - config 與 backlog 的點擊目標和之前、也和提交前相同。
  - fightr 的點擊目標差 4 處，是已知的兩群現象，根因仍未確認。
  - 提交後的執行檔在設定第 1 頁畫出三個把手。
  - 見 [routes.tsv](routes.tsv)。基準：normal150、haruuri、fightr 是 APEG 那一組提交後的紀錄；config、backlog 是堆積 D 那一組的紀錄。

## 與原版還不同、沒做與沒驗證

- **拖曳沒有實機驗**：自動點擊只能原地按 100 ms，做不出拖曳，只有探針守著。
- **設定第 4 頁的位置**：移植版的混音器沒有語音聲道、預設音量固定 100（原版約 80），所以把手畫在這些值上，和原版不同。這是聲音那一組的範圍。
- **其他有捲軸的畫面沒有看**：清單（道具、商店等）、情節回顧、立繪鑑賞也有捲軸，現在也會畫把手，軌道也會擋住後面的元件；這些畫面沒有路線到得了。商店清單在試玩時捲不動的事，也還沒有確認原因。
- **移植版的選擇**：
  - 原版放開時會把軌道的點擊轉給腳本，這裡不送。
  - 缺滑過或按住的 CG 時，原版畫灰色矩形，這裡用普通狀態。
  - 拖曳中再按右鍵或中鍵，原版會換焦點並停止拖曳，這裡照樣拖。
- **對所有 v14 遊戲的改變**：更新順序的改動不分編碼，SJIS 版的 v14 也一樣——腳本設位置造成的捲動訊息，改成排在同一次更新的輸入訊息後面，和原版相同。
- **沒做**：第 3、4 頁「初始化」按鈕的字。原版依據讀過了，但遊戲裡有 94 個按鈕帶文字，有些已經用子元件畫了字，補上可能畫兩次，要另開一組逐一確認。
- **其他平台**：Windows、Linux 沒有建置。

審查摘要見 [review.md](review.md)。
