# 按鍵與事件路徑盤點

> **本次按鍵與事件路徑盤點完成。** 已完成英文原版六類關鍵操作與並排實看；未驗證範圍及已見差異如下。最終證據與完整公開文件雙覆核均無未解 High／Medium；發布結果以 Git 與推送後核對為準。

本項盤點基準為 `04c1f34`，其中最新引擎程式為 `2ae5ab5`，libsys4 為 `247f544`。本項沒有修改引擎或探針；用途是建立按場景驗收的清單，不能解讀成所有按鍵均已可用。

## 證據種類

- **AIN 反組譯與移植原始碼靜態查核**：確認呼叫、條件、事件分派與未接通的來源。本輪未重新反組譯原版原生執行檔。
- **原生量測**：隔離存檔、固定種子、排程按下／放開與 framebuffer。這能驗證引擎收到輸入後的行為；沒有完整驗證所有實體鍵盤配置。
- **英文原版量測**：在受控私人副本完成 Ctrl、Enter、對話右鍵、已讀／未讀中鍵、Esc、設定頁一次右鍵關閉六類操作，並與原生畫面實看比較。語系、起始句位、已讀條件及 Ctrl 持有時間不同，僅依下列範圍比較行為，不宣稱跨語系像素、快進終點或全部畫面一致。
- **推論**：相同引擎設計可能適用兩個語系，但沒有把英文版量測擴張為所有繁中場景均經原版驗證。

「應可用」表示靜態路徑接通；「確定不可用」僅指表列事件路徑缺少來源；「未知」保留動態接收者、場景前置條件或尚未確認的效果。量測結果另列，不覆蓋這三種判斷。

## 三種輸入路徑

| 路徑 | 目前狀態 | 影響 |
|---|---|---|
| `CASClick`、`GlobalKeyHook` → `AFL_IsKeyDown` | 鍵盤與滑鼠鍵狀態可輪詢 | 對話推進、快進、顯示切換等可由此運作 |
| Activity 結束鍵清單 → 按下／放開輪詢 | G6 已接通 | 設定與回顧依各自結束鍵集合關閉 |
| Parts／Whole 的事件訊息 | v14 未送鍵事件 15–18、滾輪 3、右／中鍵 MouseClick 4 | 接在這些事件上的操作仍待 G5／G8 |

v14 的 `PE_UpdateInputState` 會進入專用路徑並返回，不能拿舊版分支中的鍵事件發送當作 v14 已接通的證據。腳本下游與訊息佇列雖然存在，仍需補輸入來源。因此「對話右鍵可隱藏」和「某個清單右鍵可返回」是兩項不同的驗收。

## 呼叫點對帳

私人彙整索引共 803 列、23 欄：玩家操作 43、輪詢呼叫 117、helper 綁定 118、直接事件呼叫 87、虛擬槽呼叫 393、場景訂閱 36、delegate 呼叫 9。這些混合粒度會指向同一功能，不能解讀成 803 個鍵，也不能相加當全遊戲功能數。公開只保留必要摘要，不包含私人完整總表。

| 類別 | 數量 | 計數界線 |

| helper 宣告／參照／鍵綁定／配置 | 62／300／118／88 | 彼此為不同索引，不能相加當功能數 |

| Whole 右鍵／中鍵／滾輪 Add＋Erase | 4／2／23 | 合計 29 |
| `AFL_Activity_GetLastEndKey` | 1 | 與前述直接呼叫合計 87 |
| 元件鍵事件直接 AFL 呼叫 | 0 | 不代表沒有使用；另有虛擬槽路徑 |

`AFL_SysVariable_GetKeys` 列的是資料字串的鍵，沒有直接呼叫，不是鍵盤查詢。手把功能指派代碼須先轉成實體按鍵代碼；兩者都不能直接套 Windows VK 名稱。

393 個虛擬槽呼叫中，已進一步釐清 12 條滾輪鏈：10 條玩家入口與 2 條共用支援入口。這是既有 393 列的補充，不是新增 12 個呼叫。範圍包含戰鬥站位交換、狀態與操作頁切換、卡片移動、鑑賞翻頁、客戶列表與據點回顧。`ScrollBase` 的元件滾輪 callback 為空，真正捲動走 Whole 事件；不得將兩者混為一項。

## 原生短測試

共執行 21 條：控制組 1 條、具體操作通過 16 條、整體結果保留未知 4 條。所有執行完成、錯誤為 0，且前後桌面游標相同；功能判定另由按鍵時點、訊息序列及畫面確認。

| 操作 | 本次觀察 |
|---|---|
| Enter、方向鍵下 | 等待中的完整訊息可前進一則 |
| Ctrl | 持有期間快進至教學邊界；尚未獨立證明放開後在仍可推進的對話中停止 |
| Space、Z、右鍵 | 文字隱藏後可用相同按鍵恢復，訊息沒有前進；原生右鍵隱藏時仍見粉紅按鈕與說話星形標記，不能當作整個訊息介面全隱藏 |
| A | 自動模式開啟、推進、關閉 |
| Esc | 對話開設定，再關回原畫面 |
| PageUp、方向鍵上 | 本次設定下開文字回顧，再以 Esc 返回 |
| S、中鍵 | 未讀時切換標記但不前進；受控已讀紀錄下可快進 |
| 設定頁 Space、右鍵 | 關閉當前設定層，沒有接著隱藏底層對話框 |
| Home | 進入場景回顧 UI 並能以 Esc 返回，但中央內容黑；內容正確性未知 |
| 據點 Esc、PageUp、Home | 三條路線均仍受前置教學遮罩阻擋，據點快捷鍵未驗證 |

已讀／未讀對照只有本次隔離執行產生的已讀紀錄不同。兩個已讀路線與 Ctrl 的 88 行訊息序列逐位元組相同；未讀路線維持控制組的 5 行。這是已讀條件的量測，沒有把未讀時不前進當作故障。

## 英文原版與原生對照

六類操作均有英文原版實測與畫面依據；以下判定限本次操作及條件。原生 17 PASS（含控制組）、4 未知的既有計數不變，不能把補測的英文結果加進原生分母。

| 操作 | 英文原版觀察與比較界線 |
|---|---|
| Ctrl | v3 持有 150ms 後快進；放開後相隔 35.438 秒的兩張遊戲區截圖逐像素相同，再按 Enter 可推進。原生持有 2000ms 至教學邊界，只支持持有快進；放開後在仍可推進的對話上停止仍未獨立證明。兩邊不比較速度、跳過則數或終點。 |
| Enter | v3 在等待狀態按下後訊息推進。原生亦有完整訊息等待時推進的證據；兩邊起始句位與語系不同，不比較對白或全像素。 |
| 對話右鍵 | v3 文字、按鈕及說話星形標記隱藏，再按右鍵恢復原畫面。原生文字隱藏／恢復有效，但隱藏時仍有粉紅按鈕與說話星形標記。這是已觀察的畫面差異，不能報稱訊息介面隱藏完全一致。 |
| 中鍵：未讀／已讀 | v3 未讀時可開關跳過模式，訊息不前進。v4 從已讀黃字訊息開啟模式後前進至未讀白字訊息，相隔 33.628 秒的遊戲區截圖逐像素相同，關閉模式後 Enter 可再推進。原生以受控已讀紀錄呈現可快進、未讀不前進的差別；不能宣稱兩邊已讀紀錄、起點或終點相同。 |
| Esc | v3 在對話中開啟設定；原生相應路線亦開設定。未推廣至自訂 callback、輸入元件／IME 或其他場景。 |
| 設定頁一次右鍵 | v3 一次右鍵關閉當前設定層，返回時原訊息可見；原生亦未接著隱藏底層對話。只驗證本次設定層與輸入條件。 |

英文已讀前置由同一私人副本在遊戲內建立：先快進、返回標題，再重新開始，原起點由白字變黃字後才測中鍵。英文已讀／未讀判定由操作路線及字色支持，沒有獨立解析已讀旗標檔或計算已讀總數；原生則使用受控的 88 條已讀紀錄，兩邊已讀集合未對齊。

Home 是另列的未知：英文原版 v3 按下後，遊戲區前後逐像素相同；原生則進入中央黑內容的回顧 UI，並可用 Esc 返回。原版的輸入是否送達遊戲、語系或劇本前置是否影響結果，以及原生黑內容的原因均未釐清；不能據此判定原生引擎有錯或場景回顧已完整通過。

v3 在末段回標題時出現第二個小視窗並觸發單視窗防護中止，已有完成步驟仍可作證據，但整個 session 不是全 PASS。小視窗與啟用中的回標題確認選項及操作時點相符，未保存該小視窗內容，故其身分保留為推論。v4 僅在英文私人副本取消此確認後完成已讀中鍵補測；主線要求工具 shutdown，由工具終止隔離前綴，執行器退出碼 0、清理錯誤清單為空；清理子行程另記退出碼 1，未混同為執行器退出碼。這沒有驗證遊戲 UI 退出或遊戲自行正常退出；兩輪結果分開保留，沒有以補測成功改寫第一輪中止。

## 回歸與審查

預設與 GBK 各 114 模式通過，sanitizer 診斷均為 0。第一次私人包裝錯把 GUI 的禁止桌面移動旗標帶入 headless，導致既有自動輸入探針失敗；修正包裝作用範圍後才取得上述兩組結果，引擎與探針未改。

八條一般路線加片頭共九條已完成：對白與基準逐位元組相同、錯誤 0、wrapper／engine 退出碼 0、固定種子與執行檔雜湊符合本輪、桌面游標前後相同。fightr 的 171 個點擊位置相同、目標差 58 處，依既有分群特例接受；不宣稱目標全部相同，也未判定差異由亂數造成。savedialog 的小人物圖像與 fightr 的地圖／路線狀態差異根因仍未釐清；一般路線沒有做全幀逐像素一致宣告。

片頭 t300–t349 共 50 張取樣幀與參考解碼器逐像素相同，並經獨立重算與畫面抽驗。本次 t311 對 23866 為 0 差異像素；另對歷史指定的 23900 比較為 261,004 個差異像素。歷史那次取樣對 23900 才為 0，因此兩次取到相鄰幀的差別已保留。沒有將 t349 排除，也不以 50 張取樣宣稱完整影片與音訊均通過。

英文原版六類關鍵操作與並排實看已完成；最終證據及完整公開文件已分由兩名獨立審查者覆核，均無未解 High／Medium。已完成審查的範圍與限制見 [審查摘要](review.md)，公開驗證資料見 [修前適用性](before.tsv)、[預設／GBK 模式](verify.tsv)、[九條例行路線](routes.tsv)。公開 TSV 僅保留量測摘要；畫面、對白及私人逐列索引不隨文件公開。
