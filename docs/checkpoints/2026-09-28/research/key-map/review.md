## 不可省略的限制

- 21 條原生短路線為 17 PASS（含控制組）、4 未知；Home 只確認開啟／Esc 返回，中央黑內容未釐清；三條據點快捷鍵受教學遮罩阻擋。英文 Home 未見可見變化，不能據此判定原生引擎錯誤。
- 原生右鍵隱藏文字有效，但粉紅按鈕與說話星形標記仍可見；英文原版一併隱藏。文字隱藏通過不等於整個訊息介面畫面一致。
- 原生 Ctrl 只確認持有期間推進到教學邊界，放開後在仍可繼續的對話上停止未獨立證明；英文 v3 另有放開後相隔 35.438 秒同頁及 Enter 再推進的證據，不能移用補足原生缺口。兩邊語系、句位、已讀條件及持有時間不同，不比較像素、速度、跳過則數或終點。
- 英文 v3 完成六類中的部分操作後，末段回標題因第二個視窗觸發防護中止，整個 session 不列全 PASS；v4 在私人副本取消確認後補完已讀中鍵，再依主線要求以工具 shutdown 終止隔離前綴，執行器退出碼 0、清理錯誤清單為空，清理子行程退出碼 1 另列；遊戲 UI 退出或遊戲自行正常退出未驗證。不能把補測成功回填成 v3 完整通過。
- fightr 點擊位置相同、目標差 58 處，依既有特例接受；savedialog 小人物圖像與 fightr 地圖／路線狀態差異根因仍未知。
- 片頭僅對本次 50 張取樣幀作完整像素比對。本次 t311 對 23866 為 0、對歷史指定 23900 為 261,004；不能只沿用歷史時間戳宣稱本次為 0。

- 自訂 callback、輸入元件／IME、其他恢復鍵與場景、實體鍵盤配置與手把、舊版真遊戲、SJIS、音訊及長時穩定仍有未驗證範圍。沒有重新反組譯原版原生執行檔，也沒有將英文量測推定擴張為所有繁中場景皆已原版驗證。
