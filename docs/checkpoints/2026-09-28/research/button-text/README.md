# 按鈕自己的文字

2026-10-19。程式 `d93928b`，基準 `ad1a955`，libsys4 固定 `247f544`。提交前、後的預設與 GBK 各 107 個模式 PASS。

## 症狀

v14 的按鈕從來不畫 pactex 裡自己的「文本」。所以設定第 3 頁兩個、第 4 頁七個「初始化」按鈕都是空白的，原版有字。

## 盤點

遊戲的 192 個按鈕中，有 94 個的「文本」不是空的，分三類：

| 類別 | 數量 | 內容 | 修改後 |
|---|---|---|---|
| 只有換行 | 50 | 標題畫面、音樂模式、設定的分頁鈕。分頁鈕的字是另一個文字子元件畫的 | 像素不變 |
| 有字、有 CG | 12 | 設定第 3、4 頁的「初始化」（其中一個本來就不顯示）、派遣畫面的確認鈕、館選單的樣板按鈕 | 畫出字 |
| 有字、沒有 CG | 32 | 除錯用的按鈕，以及走不到的設定頁 | 不畫（原版會畫面板加字） |

原版畫按鈕文字沒有任何條件：`0x528d80` 整段沒有分支，不看子元件，也不看文字是否為空。但在遊戲資料裡，有文字子元件的按鈕，文本全是換行；有實際文字的按鈕，都沒有文字子元件。所以照原版條件畫，不會出現重複的字。兩個審查都用自己寫的解析器重算過這個盤點，結果相同。

## 原版依據

只做靜態分析，讀多娜多娜這一支執行檔：

- **重建**（`0x528870`）：三個有效狀態（`0x528e90`、`0x528fe0`、`0x529130`）用各自的 CG（普通、滑過、按住），停用（`0x529280`）三個狀態都用停用的 CG。
- **一個狀態**（`0x528d80`）：以那個狀態的 CG 當底（命令 2），再用命令 7 畫字（`0x569410` → `0x4f4b10`；保留 CG 的 alpha）。
- **位置**（`0x5288f0`）：「文本位置」取一個位元組，照 3×3 格擺放，邊距 3，一半往零截斷；1–9 以外放在 (0, 0)。
- **量測**（`0x528aa0`）：和核取方塊相同；最後的高扣掉行間隔、寬扣掉文字間隔。

## 做法

- pactex 載入時讀按鈕的文字設定，每個狀態以自己的 CG 加字合成。
- 量測從核取方塊抽成共用函式，核取方塊的結果不變。
- 只讀 GBK 拼法的鍵，v14 之前不讀；沒有文字的按鈕結果不變。

## 驗證

- **探針 `button-text`**（8 案，說明見 [harness](../../harness/README.md)）：期望值由另寫的模型算出。修改前 6/8 失敗，另外 2 案是守衛，見 [before.tsv](before.tsv)。
- **兩組 verify**：提交前、後的預設與 GBK 各 107 模式 PASS，見 [verify.tsv](verify.tsv)。
- **和原版並排**：設定第 3、4 頁的「初始化」，字的上下緣和原版相同，左右差 0–2 px；按鈕白底的位置與大小逐像素相同。移植版的字比原版粗黑，是整體字型的差異，同一畫面沒改到的分頁鈕也一樣。
- **其他畫面**：逐影格比較，差異只出現在第 3、4 頁「初始化」的範圍；據點、系統選單、存讀檔、確認框、地圖、戰鬥都沒有多出或重複的字。
- **例行路線**：
  - normal150、haruuri、fightr、config、backlog、savedialog、garage、sysmenu 與片頭重播都跑完：exit 0、錯誤 0，對白和前一組（X／Y 旋轉）逐字相同。
  - 點擊目標除了 fightr 都相同；fightr 差 58 處，是已知的兩群現象。
  - 另跑一條切到設定第 3、4 頁的路線：最終執行檔畫出全部「初始化」。
  - 片頭 50 張畫面仍和參考解碼器逐像素相同。
  - 見 [routes.tsv](routes.tsv)。

## 沒做與沒驗證

- **按鈕的設定函式仍是空殼**（`SetButtonText`、`GetButtonText`、`SetButtonFontProperty` 等），腳本在執行時改字或改字色不會生效：
  - 派遣畫面的確認鈕：原版在滑過與按下時把字改成黑色，這裡一直是白字，壓在亮黃或近白的底上看不清楚（修改前完全沒有字）。這個畫面沒有在實機看過。
  - 館選單的樣板按鈕：帶一個佔位字串，腳本複製樣板後才設字。這個畫面目前因為 `SaveParts` 是空殼本來就走不通；修好複製之後，必須同時實作 `SetButtonText`，否則複本會畫出佔位字。
- **沒有 CG 的按鈕**：原版會畫成面板加字，這裡不畫。遊戲裡這類按鈕都看不到。
- **字型**：移植版的字比原版粗黑，是另一件事。
- **其他平台**：Windows、Linux 沒有建置。

審查摘要見 [review.md](review.md)。
